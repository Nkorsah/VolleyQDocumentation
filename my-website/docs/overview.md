# What is VolleyQ?
Volley Q allows users to create or join teams with designated captains, who can manage participation, set availability, and communicate easily with team members. Users can chat with other team members, create their own games, and view scores of past games. There will also be a map that features local volleyball courts. This application will streamline communication between players and encourage the local volleyball community.
